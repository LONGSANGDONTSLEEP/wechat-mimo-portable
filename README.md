# 微信 MiMo 助手 0.1.0（Windows x64 便携版）

解压 ZIP 到可写文件夹，双击 WeChatMiMo.exe。无需安装 Python，无管理员权限要求。
支持 Windows 10/11，使用系统内置中文 OCR；系统必须已安装简体中文 OCR 语言功能。
首次单文件 EXE 启动会临时解压运行库，退出后配置仍保留在 EXE 同目录。

## 操作
1. 登录微信，打开目标联系人或群，保持微信可见且位置、大小不变，清空输入框草稿。
2. 填入 MiMo Key。按量付费选择“按量付费”；订阅 Key 选择“Token Plan 中国”，其他地区可按控制台修改地址。模型可修改。
3. 填入与聊天顶部完全一致的标题。
4. 点击三项校准：拖动框选左侧对方消息区域（不要包含右侧自己的消息）、顶部标题区域，最后点击输入框。
5. 默认预览模式开始监听，启动时的已有消息忽略。收到新消息，连续两次 OCR 一致后生成回复。检查后可点“发送当前预览”。每次预览等待发送，不覆盖已有预览。
6. 验证无误后停止，勾选自动发送，再开始监听。
7. 按 Esc 全局停止；鼠标移至主屏幕左上角触发 PyAutoGUI 紧急停止。

## 当前范围和限制
固定一个聊天，不自动轮巡未读联系人。仅处理所框区域的文字，不识别语音/图片语义。
消息截图、聊天标题、窗口可见性受遮挡影响，窗口移动或缩放必须重新校准。
屏幕区域包含的全部对方文字会作为一次输入；不是精确按消息气泡增量提取。
发送前重新验证标题和消息，标题不符或消息变化时停止。发送使用剪贴板粘贴并按 Enter；请不要同时操作微信或在输入框留下草稿。
API 等待期间 Esc 会阻止后续发送，但请求可能直到90秒超时后才退出。
不把 API Key 写入配置，不保存聊天日志到磁盘；回复预览留在软件窗口。Key 可通过 MIMO_API_KEY 环境变量提供。
回复内容会提交到所配置的 MiMo 接口。依赖系统中文 OCR，不附带大型 OCR 模型。
自动化不保证零封号风险。

## 开发和打包
Python 3.13 x64。安装 requirements.txt 后：
python -m unittest discover -s tests
python -m PyInstaller --onefile --windowed --name WeChatMiMo --collect-all winocr --collect-all winrt app.py

MiMo 接口依据：https://mimo.mi.com/docs/zh-CN/quick-start/summary/first-api-call

本版本是独立编写的固定窗口实现，并非第三方仓库的完整功能复刻。
