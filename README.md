# 微信分身 Studio 1.0

独立 Windows 桌面 App：聊天记录管理、AI 工具箱、个人风格与联系人记忆、微信窗口 OCR 回复。
本项目实现全部工作台功能，不依赖或启动 WeTrace.exe，无需安装 Python。

## 使用顺序

1. 将便携 ZIP 解压到可写文件夹，双击 WeChatStudio.exe。不要在 ZIP 内直接运行。
2. 在“模型与工具”选择服务并测试连接：
   - MiMo：选择按量付费或 Token Plan，填写对应模型 ID 和 Key。
   - LM Studio：加载聊天模型并启动本地服务器，默认 http://127.0.0.1:1234/v1；读取本地模型列表并选择模型。
   - Ollama：启动服务并提前下载聊天模型，默认 http://127.0.0.1:11434/v1；读取本地模型列表并选择模型。
3. “聊天记录”导入 JSON、JSONL、CSV、TSV、结构化 HTML 或 TXT。支持 WeTrace 的 window.CHAT_DATA 导出。
4. 导入前检查消息、发送者、本人标记、会话、时间字段；没有本人标记时填写自己在导出中的准确称呼。未知身份不会参与风格学习。
5. “AI 工具箱”选择会话、时间和任务。先检查范围与消息，再开始分析。
6. “我的分身”查看本人例句与表达特点；“联系人记忆”保存已确认事实。
7. “回复试验室”检查回复后，再到“微信自动回复”选择窗口，在预览图确认输入框位置，启动监听。

## 日期与 AI 分析

- 最近一周、一月、一年分别是当前时刻向前7、30、365天，统一使用北京时间 UTC+8。
- 自定义日期格式 YYYY-MM-DD，包含结束日全天；结果的结束边界为下一天零点。
- 筛选完整会话，不受界面分页或导入顺序影响。无消息时直接提示，不使用旧记录补充。
- 支持秒／毫秒 Unix 时间戳、带时区 ISO 时间和常用日期文本；无效或缺失日期排除并报告数量。
- 提供对话摘要、待办提取和关键信息抽取。长记录分段后合并，显示进度；超过200段时要求缩小范围，尚未调用模型。
- “停止”阻止后续请求；已经提交的模型请求等待返回。分析结果仍需核对。
- 分析结果可保存 TXT／Markdown，分析不会操作微信。
- 本地模型建议先关闭思考模式，避免只生成思考而未返回正文。

## 记录管理与统计

- 本地 SQLite 记录库、导入去重、本人身份识别、消息全文查看。
- 按会话、消息或发送者关键词搜索，每页200条；“全部会话”支持跨会话搜索。
- 导出完整会话或全部会话为 JSON／CSV／HTML，不受搜索或分页影响。
- HTML 为离线页面，聊天文本转义为普通文字，同时内嵌结构化 JSON 便于再次导入；导入不执行 HTML 脚本。
- CSV 对可能触发电子表格公式的字段添加单引号；精确保留原文请使用 JSON／HTML。
- “聊天统计”本地计算消息数量、日期范围、活跃时段、活跃日期、发送者数量，不调用模型。
- 本版本使用已有导出文件，不直接读取微信加密数据库、不提取微信密钥。图片、语音、视频不作为文本导入。

## 风格与窗口回复

“学习”是本地提取本人风格、本人例句和联系人记忆检索，不是修改模型参数。AI输出不会作为本人的训练样本。
联系人记忆独立保存，只提交绑定联系人的相关片段，试验室可检查提示。
支持更充分回应与自然接话，不定时主动向其他联系人发消息。

自动回复只识别锁定窗口的当前聊天，不遍历好友或自动切换聊天。
启动时忽略已有旧消息；排除右侧绿色气泡，等新消息稳定后生成。
默认预览；自动发送需主动启用。发送前重新检查窗口、聊天标题、最新消息、焦点、输入位置和草稿。
聊天变化、草稿存在或窗口尺寸变化会停止或取消发送。Esc／鼠标移到主屏幕左上角可停止。
OCR 依赖可见布局，仍可能识别错误，请先使用“仅测试识别”和预览。

## 数据与便携

配置 config.json 和 data/persona.sqlite3 位于 EXE 同目录。升级时先退出旧版，再将自己的 data 和 config.json 复制到新版目录。
公开 ZIP 和单独 EXE 不含用户记录、配置或 Key。Key 仅在本次运行内存保存。
原始文件只在本机读取；点击分析、生成或开启自动回复时，相关内容提交到选定的模型服务。
本地模式不转发 MiMo Key，不自动回退云端；本地 HTTP 请求不使用系统代理。
提交片段会遮蔽常见手机号、邮箱和密钥模式，但不能保证全面脱敏，可在消息预览核对内容。
便携 EXE 自带离线 OCR 模型，首次启动需解压运行库。LM Studio／Ollama 与语言模型需另外安装、下载。
单独 EXE 可运行；ZIP 另外包含说明和许可证。

## 验证与开发

40项自动测试覆盖日期边界、空范围不调用模型、完整会话分段、联系人隔离、搜索分页、导出回读、HTML转义、风格管线、OCR气泡、发送拦截及本地HTTP协议。
独立 EXE 支持 --self-test，使用临时演示库检查各页面、窗口截图和自带OCR，不读取真实记录或发送微信。
尚未收到用户真实样本，实际文件兼容性、模型效果和微信端到端收发需在本机预览确认。

Python3.13 x64；pip install -r requirements.txt；python -m unittest discover -s tests；build.ps1 生成 dist/WeChatStudio.exe。
