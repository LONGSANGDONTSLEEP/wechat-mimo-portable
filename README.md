# 微信 MiMo 助手 0.4.0：气泡识别 OCR 便携版

## 本次修复
先检测消息气泡，再对对方气泡单独OCR；绿色气泡始终视为自己发送，即使很宽、起点在聊天区左半边也不会读入。
蓝框(IN)为对方气泡，红框(OUT)为排除的自发消息，在窗口预览中可见。可选消息区域只筛选对方气泡，不再直接把区域里的全部文字送给AI。
改用随便携包附带的RapidOCR离线中文模型。深色气泡先反色、对比度处理、放大再识别；不缩小原始文字。
按气泡序列检测新增消息，忽略旧记录、自己回复和滚动；不是每次整块区域变化都触发回复。
标题独立裁剪OCR，监听身份使用标题图像校验；单次误读或数字0不会直接判定切换聊天，标题图像变化时先暂停，连续三帧且文字也变化才停止。

## 使用
1. 解压ZIP，运行WeChatMiMo.exe，填写MiMo Key。模型全部附带，不会运行时下载。
2. 刷新窗口，选择微信主窗口或独立聊天窗口。
3. 查看窗口预览，点击输入框空白位置设置发送点；可选拖选对方消息区域。
4. 点“仅测试识别”，不用Key、不调用AI、不发送，检查标题与对方文字及气泡方向。
5. 默认预览模式开始监听，启动时旧消息忽略。确认结果再选择自动发送。
6. Esc全局停止；鼠标移动到主屏幕左上角也会停止。

窗口移动自动跟随；窗口尺寸改变需重新确认位置。程序不切换联系人。
支持MiMo按量付费/Token Plan，接口和模型可编辑。Key仅在内存中，不写配置或日志；也可使用MIMO_API_KEY环境变量。

## 验证与限制
已使用用户提供的深色微信截图做本地回归，正确读出对方文字并排除两条绿色自发消息。截图未包含在源码或发布包中。
14项自动测试通过，覆盖深/浅气泡、宽绿色气泡、重复短消息、旧记录滚动、标题图像及误点击拦截。
真实MiMo调用及实际微信端到端发送尚未验证，先使用“仅测试识别”和预览模式。
OCR仍可能漏字、错字；此版本更换模型并修复方向判断，不保证任意主题、气泡样式全部准确。
仅支持标准文本气泡，不支持图片/语音理解。只监听选定窗口当前聊天。

Windows 10/11 x64，无需Python或额外OCR语言包。首次启动单文件EXE会解压运行库和模型，可能比旧版慢。
程序旁边保存普通配置。所有截图和聊天识别只在内存中，不写磁盘。文字仅在生成回复时提交到所选MiMo接口。

## 开发
Python3.13 x64，pip install -r requirements.txt。
测试：python -m unittest discover -s tests
打包：运行build.ps1（排除无需分发的ONNX工具模块）。
独立自检：WeChatMiMo.exe --self-test（自建窗口截图及离线OCR，不操作微信、不调用MiMo）。
