# 微信 MiMo 助手 0.3.0：指定窗口 OCR 便携版

## 使用
1. 解压ZIP，运行WeChatMiMo.exe，填写MiMo Key。
2. 点击“刷新窗口”，在列表选择需要识别的微信主窗口或独立聊天窗口。只认这个窗口句柄和进程，不切换其他会话。
3. 点击“查看所选窗口 / 设置发送位置”：先确认图像就是你选择的窗口，再在图中点击输入框空白位置一次。窗口移动无需重设，尺寸改变需重新确认。
4. 如果文字识别不理想，切换“拖选对方消息区域”，在预览图中框选对方文字区域，排除头像、时间、自己的回复和输入框。区域框选可选。
5. 默认预览模式开始监听，忽略启动时旧消息。收到新消息后检查预览，可点发送。确认正确后再勾选自动发送。
6. Esc全局停止。鼠标移到主屏幕左上角也会停止。切换聊天、窗口关闭、尺寸改变或发送位置被遮挡时停止发送。

## 原理和改进
截图优先使用PrintWindow按锁定句柄读取客户区，其他窗口的内容不会混入OCR。
GPU窗口不支持后台截图时，仅在目标前台且几个关键点无遮挡时使用目标客户区截图，否则停止。
处理Windows DPI缩放，文字OCR放大2倍，发送点按客户区坐标换算。
取消未读红点自动点击和会话跳转。发送点由用户在窗口截图上确认，不再猜测输入框。
每次鼠标点击前验证实际命中窗口，粘贴和发送前检查前台焦点。

## 范围和限制
Windows 10/11 x64，需系统简体中文OCR功能，无需安装Python。支持MiMo按量付费和Token Plan，可编辑地址和模型。
API Key仅在当前进程内保存，配置写到EXE旁边；不保存聊天日志。可使用MIMO_API_KEY环境变量。
只处理指定窗口当前聊天的可见文字，不自动遍历联系人。未框选时的布局识别主要面向标准浅色微信。
指定窗口截图改善来源准确性，但不保证OCR文字完全准确。框选区域应只含对方消息，以免重复回复自己的消息。
发送会激活目标窗口。请勿在发送过程中同时操作键盘/鼠标。
已有草稿会阻止发送，不自动清空。截图变黑、无法识别聊天标题或输入框时停止。
接口最长等待90秒；停止可阻止后续发送，但不取消已经发起的API请求。
真实MiMo调用和用户微信各版本的端到端收发未完成验证，请先使用预览模式。

## 开发
Python 3.13 x64，pip install -r requirements.txt。
测试：python -m unittest discover -s tests
打包：python -m PyInstaller --onefile --windowed --name WeChatMiMo --collect-all winocr --collect-all winrt app.py
自检：WeChatMiMo.exe --self-test，在自建测试界面验证句柄截图和中文OCR，不操作微信、不调用MiMo。
MiMo文档：https://mimo.mi.com/docs/zh-CN/quick-start/summary/first-api-call
