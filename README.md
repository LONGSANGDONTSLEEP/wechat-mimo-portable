# 微信分身 Studio 2.0 预览版 5 · 阶段归档

独立 Windows 便携工作台：聊天记录、媒体、AI 分析、个人表达风格、回复试验室、锁定窗口 OCR 与完整备份，集中在同一个本机界面。

双击 `WeChatStudio.exe`，优先以 Edge 独立窗口打开。程序自带 Python 和离线 OCR，解压到可写目录即可运行，只监听 `127.0.0.1`。LM Studio / Ollama 和语言模型需要另行准备。

## 当前可用范围

- 导入 WeTrace 等工具导出的 JSON、JSONL、CSV、TSV、结构化 HTML、TXT；预览字段、本人身份和会话后确认导入。
- 读取已解密 SQLite：微信3 MSG、微信4 Msg_* / Name2Id 等兼容结构，更新时去重。
- 管理文本和非文本消息，导入媒体文件夹；支持常见图片、音视频及附件。按消息原文中的 MD5 关联媒体。
- 搜索、会话导出、聊天统计、本人表达示例和联系人记忆。
- MiMo、LM Studio 和 Ollama 共用风格与记忆。回复试验室、会话摘要、待办提取、关键信息。
- 锁定一个微信窗口，只识别当前聊天；启动时忽略旧消息，默认只生成预览。
- 完整工作区备份、校验和恢复，包含记录、设置、记忆、近期上下文及已导入媒体。

本机加密数据库的自动取密钥是**实验功能**。微信4.1.15.56尚未通过本机兼容性验收，不能保证直接读取其原始加密库。提供已有数据库密钥时，会认证数据库首页，再解密只读副本及已提交 WAL；密钥仅保留在本次内存。不可读取的微信进程会显示具体权限原因。

新增独立的“登录阶段取钥”：选择账号目录与微信主进程，先检查采集环境，再开始采集。只有后台显示“采集已就绪”后，才在官方微信中手动登录；已登录时也可尝试打开聊天触发数据库访问。环境检查、登录完成均不等于取钥成功，候选必须通过所选账号数据库认证。程序会在所选进程内临时安装观察器，采集结束、取消或失败后解除；不会代为登录、退出或重启微信。此流程与原有只读内存扫描分开，均不显示或保存密钥。开始采集会停止本工作台的自动回复，清理完成前不能启动冲突操作。

DAT 图片与 SILK 音频可保留原文件，目前不能直接解码播放。无哈希关联的文件仍可在媒体库独立查看。OCR 会受窗口布局影响，微信自动发送仍需实际环境验收。

## 使用顺序

1. **数据接入**：优先导入已有导出文件或已解密数据库，媒体文件夹单独导入。身份未知的记录不会作为本人风格样本。
2. **模型与设置**：选择服务，填写准确模型 ID，点击测试连接。LM Studio 需加载模型并启动本地服务器；默认地址 `http://127.0.0.1:1234/v1`，Ollama 为 `http://127.0.0.1:11434/v1`。本地服务未启用认证时 Token 留空。
3. **个人分身**：核对本人表达示例，添加已确认的联系人事实。“学习”是例句和记忆检索，不是训练模型权重；AI 输出不会成为本人的样本。
4. **AI 工具箱**：先检查日期范围和实际消息，再生成结果。最近一周、一月、一年按当前北京时间向前7、30、365天计算，无近期记录时不会回退旧记录。自定义日期包含结束日全天。
5. **回复试验室**：查看实际提示与生成正文。这里只生成预览，不操作微信。
6. **微信自动回复**：锁定窗口，先测试 OCR，再在截图确认输入框。启用自动发送前请检查识别结果。窗口尺寸变化、聊天变化、已有草稿或焦点异常时取消发送。Esc 或鼠标移到主屏左上角可停止。
7. **备份与恢复**：把下载的备份保存到工作区外。选择备份后，程序先显示替换确认；取消不上传。校验通过后先创建恢复前安全备份，失败则回滚，结果显示备份位置。

本地模型默认请求关闭思考；模型不支持时选“使用服务默认设置”。回复不合适时调整补充要求与本人身份，增加输出上限只改变长度预算。模型输出仍需核对。

## 数据、迁移与容量

`config.json` 和 `data/` 位于 EXE 旁边。升级前退出旧版，替换 EXE 并保留这两个位置。不要删除聊天数据来修复配置问题。旧版数字文本和 BOM 配置会迁移；无效配置显示提示，保存后写入规范值。

API Key、服务 Token 和数据库密钥不写进配置或备份，关闭后需要重新填写。切换服务或地址会清除旧认证。本地模式不回退云端；使用 MiMo 时，参与生成的资料才提交给所选 MiMo 服务。

- 聊天记录单文件导入上限150MB；大型导出请按联系人拆分，或使用完整备份迁移。
- 媒体单文件上限512MB。
- 完整备份 ZIP 上传上限9GB，解包文件总量上限8GB，清单上限8MB。大备份使用流式上传。
- 备份校验同时核对外层清单、核心记录库及媒体实际哈希、资产 ID、文件名和登记大小。缺失或损坏媒体会明确报错。
- JSON/CSV/HTML 导出保留消息类型；本应用 CSV 的公式保护标记可在回导时还原原文。

## 从源码构建

Windows + Python3.13 x64，安装 `requirements.txt` 后执行 `build.ps1`。入口为 `studio_web.py`。

```powershell
python -m unittest discover -s tests -q
node --test tests/frontend.test.cjs
.\dist\WeChatStudio.exe --self-test
.\dist\WeChatStudio.exe --capture-self-test
```

`--capture-self-test` 只附加程序自己启动的人工测试进程，结果保存在 EXE 同目录 `capture-self-test.json`；不接触微信。该检查通过也不代表当前微信版本已经兼容。

项目使用 MIT 许可证，依赖许可证在 `THIRD_PARTY_LICENSES/`。WeTrace 是格式兼容参考，本项目不分发或启动 WeTrace 二进制。登录采集参考 [wechat-decrypt 的 MIT 源码](https://github.com/freanocank/wechat-decrypt)，静态定位、调用约定过滤、隔离采集、数据库认证与应用集成在本项目实现；使用 Frida 和 Capstone 运行库。
